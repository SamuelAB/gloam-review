# Gloam Review

Review stills and videos of Gloam VR work in progress, kept out of the main repo so its history stays light.

Add a review: put media in `media/<date>-<topic>/` and add an entry to `reviews.json` with `posted` (ISO time with offset, e.g. `2026-10-09T13:51-04:00`), shown on the page in Montreal time. The page (`index.html`) renders the list newest first.
